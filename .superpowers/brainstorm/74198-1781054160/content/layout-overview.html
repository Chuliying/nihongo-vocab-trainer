A — 單頁雙模式

合併成一個 / 路由，頂部切換 List／Card。/practice 廢除。狀態共用，切模式不影響 filter。

優點

  • 最簡潔，無跳頁
  • Filter 自然共用

缺點

  • 需重構路由

B — 兩頁共享 Filter 狀態

保留 / 和 /practice 兩個路由，透過 localStorage 共享 filter。列表頁有「進入練習」按鈕帶著 filter 跳轉。

優點

  • 改動較小
  • 練習頁全螢幕沉浸

缺點

  • 頁面跳轉有斷點感
  • Filter 同步要額外處理

C — 列表為主，卡片浮層

列表頁點「開始練習」後，卡片從底部滑入覆蓋列表（全螢幕 overlay/sheet）。Filter 自然共用，關掉卡片回到列表原位。

優點

  • 沉浸感強，無路由跳轉
  • 關閉回到原滾動位置

缺點

  • 卡片需要 overlay 管理
  • 深連結較複雜
